# 灯塔（Lighthouse）

SillyTavern 扩展：**API 中转站管理**。统一维护你用的中转站列表，后续在此之上逐步补齐读密钥、代发余额/模型请求、验真（防模型偷换/掺水）。

## 功能

- **中转站列表管理**（v0.2.0）：添加 / 编辑 / 删除中转站，字段为名称、Base URL、分类、备注；列表按分类分组；本地持久化。

## 规划（逐块推进）

1. ✅ 中转站列表管理 + 分门别类
2. ⬜ 可爱风格（面板美化）
3. ⬜ 切换 —— 选中中转站后切换酒馆 API 连接（不动其它设置）
4. ⬜ 读密钥 —— 读酒馆已保存的 API key
5. ⬜ 代发余额 / 模型请求 —— 服务端代理转发，绕 CORS + 隐藏 key
6. ⬜ 验真 —— 防模型偷换 / 掺水

## 安装

把本目录放进 SillyTavern 的 `public/scripts/extensions/third-party/lighthouse/`，刷新后点酒馆的「扩展程序」（魔杖）图标，弹出的菜单里会多一个「灯塔」项（和 Serendipity 同位置），点它打开面板。

## 结构

- `manifest.json` —— 扩展清单（name = `lighthouse`）
- `index.js` —— 前端面板逻辑
- `style.css` —— 面板样式（深夜 + 灯塔光束配色）
